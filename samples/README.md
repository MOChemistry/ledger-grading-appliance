# Sample assignments

Blank master documents in the format described in [docs/ASSIGNMENT_FORMAT.md](../docs/ASSIGNMENT_FORMAT.md), as they would be placed in `Ledger Workspace/01 Master Assignments`. To run a test batch, print one at 100 % scale, write a three-digit pseudonym on each page, fill in the boxes, scan at 300 dpi and follow [INSTALL.md](../docs/INSTALL.md), Part E. A few use an ID label other than "Bartonian ID"; the label is set per machine.

They were written for development and testing, not as model instruction; see [DISCLAIMER.md](../DISCLAIMER.md).
