Thank you for evaluating The Ledger.

## Bug reports and evaluation questions — welcome

Open an **Issue** for anything that doesn't work as the documentation says. Please include:

- what you did (the step in `docs/INSTALL.md`, or the button you clicked),
- what you expected,
- what happened, with the exact text of any error,
- your Debian version and the first line of `build-ledger.sh`'s log if the problem is in the build.

**Never paste an API key, an `/etc/paragon/.env` file, a scan, a conspectus PDF, a roster, or anything that identifies a student into an issue.** Evaluation should use test material only.

Use **Discussions** for questions and ideas. Answers there are offered informally, are not professional advice, and do not change the terms in [DISCLAIMER.md](DISCLAIMER.md).

## Pull requests — not yet

Pull requests are not accepted at this time. Contributions will require a signed contributor license agreement, which is not ready. Until it is, a pull request will be closed with thanks and a pointer to this file.

If you have a fix, open an Issue describing it.
